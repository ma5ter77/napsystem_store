# Бэклог доработок

Живой бэклог: **https://claude.ai/artifact/SuaJbgYtbHjtc9r4pYJGWu** (страница с общей базой задач; доступ выдаёт владелец через «Поделиться»). Ссылка есть на странице продукта «О версии».

## Поля задачи

| Поле | Значение |
|---|---|
| Номер | `NAP-###`, присваивается автоматически и не меняется |
| Тип | Интерфейс · Сервис · Функционал · Инфраструктура · Интеграции · ТЗ и документы |
| Приоритет | P1 критично · P2 важно · P3 улучшение · P4 когда-нибудь |
| Статус | Бэклог → Следующие → В работе → На проверке → Сделано; также Заблокировано, Отложено |
| Целевая версия | релиз продукта (SemVer), в котором задача должна выйти |
| Раздел ТЗ | версия и раздел ТЗ или номер критерия приёмки, например `ТЗ v1.0 §13, критерий 33` |
| Описание, критерии готовности | что сделать и как проверить |

## Как работаем

1. Новая идея или замечание — задача со статусом «Бэклог», с описанием и критериями готовности.
2. На планировании задачи релиза переводятся в «Следующие» и получают целевую версию.
3. Изменение требований оформляется задачей типа «ТЗ»; после согласования выходит новая версия ТЗ (`docs/spec/README.md`).
4. Задача закрывается («Сделано») релизом: номер задачи указывается в `CHANGELOG.md`, версия — в `release.json`; стенд показывает её на странице «О версии».
5. Блокеры извне (документация кресла, ключи, решения бизнеса) — статус «Заблокировано» с причиной в описании.

## Нумерация релизов

`0.2.x` — исправления и стенд, `0.3.0` — следующий функциональный релиз MVP, `1.0.0` — первый production-релиз (требует закрытия всех P1 и production-зависимостей).
