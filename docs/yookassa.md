# ЮKassa: покупатели из России (NAP-012)

Цены в рублях оплачиваются через ЮKassa (карты «Мир», СБП, ЮMoney и др. — на странице ЮKassa), все остальные
валюты — через Stripe (docs/stripe.md). Выбор автоматический по валюте цены.

## Что умеет магазин

| Возможность | Как |
|---|---|
| Разовая покупка цифрового контента, заказ оборудования в рублях | `POST /v3/payments` с `Idempotence-Key`, переход на страницу ЮKassa (`confirmation: redirect`), `capture: true` |
| Онлайн-чек по 54-ФЗ | в каждом платеже `receipt`: e-mail покупателя, позиции (контент — «услуга», оборудование — «товар», доставка — «услуга»), ставка НДС из `NAP_YOOKASSA_VAT_CODE` |
| Подтверждение оплаты | уведомление ЮKassa не подписано, поэтому магазин **перечитывает платёж из API** по его id и действует по ответу API; плюс проверка, что запрос пришёл из сетей ЮKassa |
| Возвраты | `POST /v3/refunds` + уведомление `refund.succeeded` |
| Валюта покупателя | рубли — явный выбор внизу страницы или регион браузера ru-RU |
| Не реализовано | рекуррентные подписки (этап 2: сохранённый способ оплаты + списания по расписанию), выплаты авторам через ЮKassa |

## Что сделать владельцу

1. **Договор с ЮKassa** на российское юрлицо или ИП (yookassa.ru → Подключиться). Нужны сайт с офертой,
   реквизитами и контактами — они уже есть в правовых документах (заполнить заглушки).
2. **Онлайн-касса (54-ФЗ):** в личном кабинете ЮKassa подключить «Чеки от ЮKassa» или свою кассу. Бухгалтер
   выбирает ставку НДС: `NAP_YOOKASSA_VAT_CODE` = 1 (без НДС, УСН/патент), 4 (20 %), 11 (22 % с 2026) и т. д.
3. **Тестовый магазин:** в кабинете ЮKassa есть тестовый магазин — shopId и секретный ключ `test_…`.
4. **На сервере** в `shared/.env`: `NAP_YOOKASSA_SHOP_ID=…`, `NAP_YOOKASSA_SECRET_KEY=…`,
   `NAP_YOOKASSA_VAT_CODE=…`, затем Actions → store-ops → restart.
5. **HTTP-уведомления** в кабинете ЮKassa: URL `https://store.napsystem.com/api/v1/webhooks/payments/yookassa`,
   события `payment.succeeded`, `payment.canceled`, `refund.succeeded`.
6. Авторы могут указать цену в рублях в кабинете → «Цена».
