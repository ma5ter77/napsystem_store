# Стенд разработки и предпросмотр (NAP-088)

Пока арендованного сервера нет, магазин собирается и проверяется так:

- **Код** — только в GitHub (ma5ter77/napsystem_store). Рабочая среда Claude временная: её можно
  пересоздать в любой момент, ничего не теряется.
- **Стенд Claude** — полный магазин без Docker (PostgreSQL, Redis, API, Celery, Next.js) с демо-данными:
  `bash ops/dev/stand.sh up` (первый раз), `restart --build` после изменений, `status`, `logs api|worker|web`,
  `down`. Снаружи недоступен; Claude проверяет на нём изменения, E2E и доступность перед PR.
- **Проверки** — CI в GitHub Actions на каждый PR (тесты, E2E, Docker, приёмка выкладки).
- **Предпросмотр для владельца** — Actions → preview → Run workflow (ветка, минуты ≤ 120). На runner
  поднимается весь Docker-стек, ссылка вида `https://….trycloudflare.com/ru` приходит комментарием в
  задачу «Предпросмотр» (GitHub пришлёт письмо). Только демо-данные; по истечении времени стенд удаляется.
  Расход: минуты Actions на всё время предпросмотра.
- **Сервер** — когда будет арендован: docs/vps-deploy.md; после настройки выкладка идёт сама.
