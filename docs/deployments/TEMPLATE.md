## Откат
Сначала plan-only rollback с expected-current и env-sha256 по docs/release-safety.md. Применение отдельно разрешается владельцем; при несовместимой схеме — остановка и отдельный план восстановления БД.

## Контроль безопасного выпуска
- [ ] SHA-256 артефакта и точный commit проверены
- [ ] ожидаемый current/env hash совпадают
- [ ] images/frozen config предыдущего выпуска сохранены
- [ ] CI на точном SHA зелёный
- [ ] ресурсный допуск и закрытый demo-доступ подтверждены
- [ ] нет изменений схемы/окружения без отдельного плана
- [ ] результат выпуска/восстановления записан в release-state.json
