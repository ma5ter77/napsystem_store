# Аудит доступности WCAG 2.1 AA (NAP-043)

Дата: 31.10.2026. Версия: ветка `codex/a11y-audit` от `master` 0.7.1.

## Как проверяли

- **Автоматически:** `frontend/e2e/a11y.cjs` прогоняет axe-core 4.10.3 с правилами `wcag2a`, `wcag2aa`, `wcag21a`, `wcag21aa` по 70 страницам: гость и пять ролей (покупатель, разработчик, поставщик, модератор, администратор), на русском и английском. Добавлен в CI.
- **Клавиатура:** тот же скрипт проверяет, что первым по Tab идёт ссылка «Перейти к содержимому», у каждого из первых 40 элементов в порядке табуляции есть видимый фокус и фокус нигде не застревает.
- **Перестроение (1.4.10):** главная, каталог, карточки, корзина, «О версии», вход и регистрация на ширине 320 px — горизонтальной прокрутки нет. Таблицы прокручиваются внутри своего блока. На 390 px проверяет QA-обход `e2e/sweep.cjs`.
- **Вручную:** выбор оценки звёздами, плеер, анкеты до и после сеанса, сообщения о статусе, языковые атрибуты, анимации.

## Найдено и исправлено

| Критерий | Что было | Где | Исправление |
|---|---|---|---|
| 1.4.3 Контраст (serious) | Зелёный, жёлтый и розовый текст статусов на светлом фоне давал 4,05–4,48 : 1 при норме 4,5 : 1 | бейджи статусов на 20 страницах | `--ok` #2a6f47 (5,2 : 1), `--warn` #83580c (5,5 : 1), `--right` #9c4069 (5,2 : 1) |
| 4.1.2 Имя элемента (critical) | Выпадающие списки ролей без подписи | «Администрирование → Пользователи» | `aria-label` «Роль для {email}» |
| 1.1.1 Текстовая альтернатива (serious) | Обложки-рисунки с `role="img"` и пустой подписью | кабинет разработчика | без названия обложка помечена декоративной (`aria-hidden`), с названием — `role="img"` и подпись |
| 2.4.1 Обход блоков | Не было способа пропустить шапку | все страницы | ссылка «Перейти к содержимому» первой по Tab, `main` принимает фокус |
| 4.1.2 / 1.3.1 | Полоса прогресса сеанса — только картинка; у ползунков анкеты значение без смысла | плеер | `role="progressbar"` с временем «12:30 / 45:00»; у ползунков `aria-valuetext` со значением и подписями краёв шкалы |

Результат после исправлений: **0 нарушений** на 70 страницах, клавиатурные проверки пройдены, браузерные сценарии RU/EN зелёные.

## Уже соответствовало

- Видимый фокус у всех элементов (`:focus-visible`), у выбора звёзд — рамка вокруг звезды.
- Оценка звёздами сделана на настоящих радиокнопках: стрелки, Tab и экранный диктор работают; в отображении звёзд число всегда есть в доступном имени.
- Поля форм подписаны; ошибки — `role="alert"` с перечнем полей; невалидные поля — `aria-invalid`.
- Уведомления о результате действий — `role="status"`.
- `lang` у страницы и у контента на другом языке (отзывы, тексты авторов).
- Анимация «загрузки» отключается при `prefers-reduced-motion`.

## Ограничения

- Проверка автоматическая и клавиатурная. С VoiceOver/NVDA вручную не тестировали — это рекомендуется перед публичным запуском.
- Вкладки сделаны кнопками с `role="tab"` и `aria-selected`. Переключение стрелками по шаблону ARIA Tabs не реализовано, по Tab все вкладки доступны. Улучшение можно сделать отдельно.
- Содержание аудио — ответственность авторов. Модерация проверяет технические параметры, не текстовые расшифровки.
