# NAP Store — краткая инструкция

**Автору.** Зарегистрируйтесь с отметкой «Я автор» → «Новое приложение» → вкладка «Аудио и конвертер»: загрузите WAV/FLAC/MP3/M4A (до 1 ГБ, 120 мин, моно или стерео) → выберите профиль → «Конвертировать». Прослушайте исходник и результат, проверьте QA-отчёт (частоты несущих, true peak, LUFS). Во вкладке «Описание» заполните RU/EN-тексты, требования к оборудованию и подтвердите права. «Программа» — соберите сеансы из готовых треков. «Цена» — разовая покупка, подписка или бесплатно. «Версии и публикация» — отправьте на модерацию; после одобрения нажмите «Опубликовать». Для изменений создаётся новая версия. Доход: 70 % вам, 30 % платформе; см. вкладку «Доходы». SDK-ключи — только для сервера.

**Покупателю.** Выберите приложение, послушайте фрагмент, купите или оформите подписку (в demo — тестовая оплата). В «Библиотеке» нажмите «Слушать», выберите устройство (наушники в браузере или симулятор кресла), пройдите проверку L/R, анкету «до» (можно пропустить), сеанс и анкету «после». Это самооценка, а не медицинский показатель. «Подобрать оборудование» в карточке покажет комплекты и недостающие компоненты; отметьте, что у вас уже есть.

**Оборудование.** Корзина делится на заказы по продавцам. В заказе укажите адрес (поля зависят от страны), рассчитайте доставку, выберите тариф и оплатите. Для кресла сначала запросите расчёт доставки у поставщика. Срок доставки — оценка. Пошлины при DAP оплачивает получатель.

**Поставщику.** «Кабинет поставщика» → заказ → «Принять в работу» → упаковочные места → этикетка (или свой перевозчик с трек-номером) → «Передано перевозчику» → события доставки. Возвраты: одобрение → получение → проверка (склад пополняется только после проверки) → денежный возврат отдельно.

**Модератору/администратору.** Модерация: прослушивание, QA, manifest, решение с комментарием. Администрирование: роли, профили DSP (новая версия), финансы и выплаты, аудит, очереди.
