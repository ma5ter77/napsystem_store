# Дизайн NAP Store (NAP-089, NAP-090)

Направление — спокойный, светлый, «продукт в центре» интерфейс в духе Apple Store: много воздуха, крупная
типографика, нейтральная палитра и один цвет действия. Это вдохновение, а не копия: логотипы, шрифты и
материалы Apple не используются.

## Токены (frontend/app/globals.css, `:root`)

| Роль | Значение | Где |
|---|---|---|
| Холст | `#ffffff` | фон страниц |
| Туман `--fog` | `#f5f5f7` | секции, панели, подвал |
| Чернила `--slate` | `#1d1d1f` | основной текст |
| Вторичный `--muted` | `#6e6e73` | подписи (4,9:1 на белом) |
| Линии `--line` / `--hair` | `#d2d2d7` / `#e8e8ed` | границы, разделители |
| Действие `--action` | `#0066cc` | ссылки и основные кнопки (5,6:1) |
| Несущая L / R | `#2f6fa3` / `#b03f6f` | только фирменный мотив и обозначения L/R |
| Статусы | ok `#1d7a3e`, warn `#8a5300`, bad `#c0352b` | всегда вместе с иконкой и текстом |

Шрифт — Inter Variable из пакета `@fontsource-variable/inter` (хранится в проекте, не загружается с Google;
на устройствах Apple при отсутствии — системный SF). Шкала: 13 / 17 (текст) / 21 / 28 / 40 / 40–64 (главная).
Заголовки 650–700, отрицательный трекинг на крупных размерах. Радиусы по иерархии: элементы управления 10,
плитки и медиа 18, крупные плитки главной 28, кнопки и чипы — пилюли. Тени только у всплывающих слоёв
(меню аккаунта); шапка — полупрозрачная с размытием.

## Принципы

1. **Одна смелая вещь.** Яркий элемент один — две несущие L и R. Всё остальное тихое.
2. **Где я и что дальше.** У каждой внутренней страницы есть хлебные крошки, заголовок и строка
   «что здесь можно сделать». У каждого статуса — лента этапов и подсказка «Что дальше».
3. **Статус — не только цвет.** Цвет + знак (✓, номер, !) + текст; для экранных читалок — состояние словами.
4. **Слова — часть интерфейса.** Кнопка называет действие («Выбрать приложение»), ошибки говорят, как
   исправить, пустой экран предлагает следующий шаг. Без заглавных меток и «→» в кнопках.
5. **Движение — только в ответ на действие** (раскрытие меню, наведение на карточку); `prefers-reduced-motion`
   отключает всё.
6. **Качество по умолчанию.** Работает от 360 px, видимый фокус, контраст ≥ 4,5:1, 0 нарушений axe
   (`node e2e/a11y.cjs`).

## Компоненты

- `components/nav.tsx` — `Breadcrumbs`, `PageHead`.
- `components/OrderTimeline.tsx` + `lib/orderSteps.ts` — лента этапов заказа и «Что дальше».
- `components/icons.tsx` — линейные иконки (корзина, профиль, меню, галочка).
- `components/Art.tsx` → `HeroWaves` — фирменный мотив главной.
- Шапка: текстовая навигация, иконка корзины со счётчиком, меню аккаунта (Escape и клик вне закрывают).
- Подвал: короткий дисклеймер, «Методика и ограничения» раскрывается, колонки ссылок.

## Процесс (NAP-089)

Каждое изменение интерфейса: план (палитра, шрифт, сетка, принципы) → сверка с этим документом →
реализация → скриншоты desktop 1440 и mobile 390 «до/после» → самопроверка → a11y и E2E.
