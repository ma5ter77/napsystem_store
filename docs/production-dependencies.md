# Production-зависимости и их статус

| Зависимость | Что нужно | Статус в поставке |
|---|---|---|
| Кресло NAP SYSTEM | протокол/модель, пределы команд, калибровка, подтверждённый аудиотракт, виброакустический контракт | **нет данных**: `NapChairAdapter` отказывает; работают `SimulatedDeviceAdapter` и веб-проигрыватель |
| Датчики (пульс, HRV, ЭЭГ) | модели, протокол, метод расчёта и контроль артефактов | **нет**: приём HR/HRV по API с согласием; ЭЭГ не принимается |
| Утверждённые DSP-профили | профили и границы, согласованные методистами | demo-профили `alpha/theta/beta-demo-v1` (инженерные) |
| Платёжный оператор | выбор оператора, страна компании, валюта, аккаунты | **Mock — работает**; Stripe test — адаптер реализован, контрактные тесты пройдены, **live sandbox: not run** (нет ключей); выплаты через Connect — not run |
| Налоги | налоговая модель, ставки, отображение | demo: налог 0 (поле `tax_minor` и счёт `tax:payable` предусмотрены) |
| Поставщики, SKU, BOM | подтверждённые модели, характеристики, цены, условия аппаратных расчётов | **demo-данные** (помечены в UI) |
| Склады, остатки | реальные склады и учёт | demo-склады в DE |
| Упаковка, маршруты, тарифы | тарифы перевозчиков, ограничения груза (батареи), freight-партнёры | **Mock — работает**, ручной режим — работает; EasyPost test — адаптер реализован, контрактные тесты пройдены, **live: not run** |
| Таможенные данные | описания, HS-коды, страна происхождения от поставщика | структура есть; HS-коды не выдумываются (`not_provided`) |
| E-mail/уведомления | SMTP/провайдер, домен отправителя | уведомления рендерятся RU/EN и сохраняются; **транспорт не подключён** |
| Инфраструктура | домен, TLS, секреты, S3, резервное копирование, мониторинг | Docker Compose для локального запуска (**в этой среде not run** — нет доступа к Docker Hub); S3 проверен на эмуляторе (moto) |
| Хостинг вычислений конвертации | CPU-узлы с ffmpeg/soxr, диск под spool | benchmark приложен |
