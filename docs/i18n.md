# Русский и английский

- Публичные страницы: `/ru/...` и `/en/...`; `<html lang>`, `<title>`, `description`, `canonical` и `hreflang` (`ru`, `en`, `x-default`) формируются на сервере (SSR).
- Первый визит: язык браузера (`Accept-Language`), резервный — русский; выбор хранится в cookie `nap_locale` и в профиле (`users.locale`). После входа применяется язык профиля.
- Переключатель меняет только префикс пути и сохраняет query: открытая карточка, авторизация (cookie-сессия) и корзины (серверные) не меняются, новых товаров/заказов не создаётся. Формы адреса и нового приложения хранят черновик в `sessionStorage` и переживают переключение.
- Словари UI: `frontend/messages/{ru,en}.json`, генерируются из пар `scripts/messages_src.py` (ключ всегда есть в обеих локалях), параметры `{name}` и множественное число `{count, plural, one {...} few {...} many {...} other {...}}` через `Intl.PluralRules`. Словари сервера (ошибки, статусы, письма): `backend/app/i18n/{ru,en}.json`, правила множественного числа RU/EN реализованы на Python.
- Автоматическая проверка: `npm run check-i18n` (паритет ключей и наличие всех ключей, используемых в коде; выполняется при сборке Docker-образа) и тест `backend/tests/test_i18n_api.py` (паритет и наличие переводов для каждого кода ошибки в коде).
- Контент (карточки приложений и товаров, условия поставки и возврата) хранится отдельными переводами со статусами; отсутствие перевода = `missing`. Внешний авторский текст без перевода показывается в оригинале с пометкой языка (`lang` на элементе + бейдж). Demo-каталог имеет опубликованные RU/EN.
- Язык интерфейса, язык описания, язык аудио (`content_language`) и страна доставки — независимые параметры; переключение языка не меняет аудио, цену, валюту, остатки и права; локаль меняет только формат чисел и дат.
- Язык заказа сохраняется (`hardware_orders.locale`, `digital_orders.locale`) и используется в уведомлениях об оплате, отправке, проблеме и возврате.
- Машинные коды API (`error.code`) и методы SDK от языка не зависят; `error.message` локализован по `X-Locale`/cookie/`Accept-Language`.
