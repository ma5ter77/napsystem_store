# Secure Player: защищённое прослушивание без интернета (NAP-104, ТЗ v2.1 M5)

Статус: **веб-часть, этап 1 — сервер и формат.** Готовы пакет `.napx`, ключи устройств, подписанные офлайн-лицензии,
API и чтение пакета в браузере (`frontend/lib/napx.ts`). Следующий этап — кнопка «Сохранить для прослушивания без
интернета» в плеере и список устройств в профиле. Нативный вывод (WASAPI / CoreAudio / ALSA-PipeWire) и поставка в
мобильные приложения объединены с NAP-066 и стоят на паузе вместе с ним.

## Что получает слушатель

Программа, сохранённая на устройство, хранится только в зашифрованном виде. Её нельзя скопировать на другое
устройство или отдать другому человеку: ключ к ней выдаётся этому устройству и только на срок лицензии. Любое
изменение файла обнаруживается до воспроизведения. Если устройство отключено в профиле, покупка возвращена или
подписка закончилась, плеер при следующем выходе в сеть удаляет копию.

**Честные ограничения** (инвариант ТЗ): это не абсолютная защита от копирования — чтобы играть, плеер расшифровывает
звук; срок лицензии без интернета проверяется по часам устройства.

## Как устроено

```
браузер                                             сервер
  P-256 ключ устройства (WebCrypto, non-extractable)
  POST /me/license-devices {public_key: SPKI} ───────▶ license_devices (только открытый ключ)
  POST /me/leases {device_id, app_id, session_key,
                   layout} ──────────────────────────▶ проверка покупки/подписки (access_for)
                                                       .napx один раз на файл доставки (content_packages):
                                                         CEK случайный, хранится обёрнутым KEK (AES-256-GCM)
                                                       лицензия (JWS EdDSA): аккаунт, устройство, программа,
                                                         manifest_sha256, срок, CEK зашифрован ключу устройства
  ◀──────────── lease + подписанная ссылка на .napx
  офлайн: проверка подписи и срока → ECDH → CEK → расшифровка по сегментам
  онлайн: GET /me/leases/{id} → active / expired / revoked → удалить копию, если не active
```

### Пакет `.napx` v1

| Часть | Содержимое |
|---|---|
| Заголовок | `NAPX`, версия 1, 3 нулевых байта |
| Manifest | u32 длина + канонический JSON: `content_id`, `sha256` и `size` исходного файла, `content_type`, `segment_size` (1 МиБ), `segments`, `cipher`, `nonce_prefix`, `key_id` |
| Подпись | u32 64 + Ed25519 от байтов manifest |
| Сегменты | AES-256-GCM каждого сегмента, nonce = `nonce_prefix ‖ u32 номер`, AAD = `SHA-256(manifest) ‖ u32 номер ‖ u8 последний` |

Номер сегмента и признак последнего в AAD не дают переставить, выбросить или обрезать сегменты; хэш manifest в
AAD привязывает сегменты к своему пакету даже там, где браузер не умеет проверять Ed25519.

### Лицензия (lease)

Compact JWS с `alg: EdDSA`, `typ: nap-lease+jws`. Поля: `lid`, `sub` (аккаунт), `dev` (устройство), `app`, `ver`,
`session`, `layout`, `content_id`, `sha256`, `manifest_sha256`, `iat`, `exp`, `key` — CEK, зашифрованный для
устройства: эфемерный ключ P-256 (`epk`), ECDH, HKDF-SHA256 (`info = "nap-lease-v1|" + lid`), AES-256-GCM с AAD = `lid`.

Срок: `NAP_LICENSE_OFFLINE_DAYS` (30 дней), для подписки — не дольше оплаченного периода.

### API

| Метод | Назначение |
|---|---|
| `GET /api/v1/licenses/public-key` | открытый ключ Ed25519 (проверка manifest и лицензий) |
| `GET/POST /api/v1/me/license-devices` | устройства с офлайн-копиями; регистрация открытого ключа P-256 (SPKI, base64) |
| `DELETE /api/v1/me/license-devices/{id}` | отключить устройство: все его лицензии отзываются |
| `POST /api/v1/me/leases` | лицензия + ссылка на пакет для программы (`layout`: headphones / acoustic_3_0 / surround_5_1 / surround_7_1) |
| `GET /api/v1/me/leases/{id}` | статус лицензии: `active` / `expired` / `revoked` (+ причина) |

Ошибки: `no_entitlement` (нет покупки/подписки), `license_device_limit` (предел устройств, `NAP_LICENSE_MAX_DEVICES`),
`license_device_revoked`, `secure_key_rotated` (сменён KEK — скачать заново).

### Ключи сервера

`NAP_CONTENT_MASTER_KEY` (KEK) и `NAP_LICENSE_SIGNING_KEY` (seed Ed25519) — base64 от 32 байт,
`python -m app.tools.secure_keys`. Без них выводятся из `NAP_SECRET_KEY` (HKDF). Порядок установки — OPERATIONS.md.
